## 3. 数据模型（新增 6 表）

```prisma
model Post {           // 内容主体
  id String @id; title String; body String
  mediaPaths String[]; status PostStatus @default(DRAFT) // DRAFT|READY|PUBLISHED|FAILED
  fromHotlist Boolean @default(false); createdAt DateTime @default(now())
}
model PostVariant {    // 每平台适配版
  id String @id; post Post @relation(fields:[postId],...); postId String
  platform Platform;  // GZH|DOUYIN|XHS
  title String; body String; tags String[]; coverPath String?
  status VariantStatus @default(DRAFT) // DRAFT|APPROVED|PUBLISHED
  formatCheck String?  // 字数/标签校验 JSON
}
model PublishJob {     // 排期
  id String @id; variant PostVariant @relation(...); variantId String
  scheduledAt DateTime; status JobStatus @default(PENDING) // PENDING|RUNNING|SUCCESS|FAILED|CANCELLED
  lastError String?
}
model PublishLog {     // 执行留痕
  id String @id; job PublishJob @relation(...); jobId String
  stage LogStage;      // PLAN|PUBLISH|VERIFY|COLLECT
  detail String; screenshotPath String?; createdAt DateTime @default(now())
}
model AccountProfile { // 账号画像(P2 起填,P1 占位)
  id String @id; platform Platform; handle String
  positioning String; style String; tone String; constraints String?
}
model PostMetric {     // P3 复盘数据
  id String @id; variant PostVariant @relation(...); variantId String
  collectedAt DateTime; views Int?; likes Int?; comments Int?; followerGained Int?
}
```

约束：每 Post 每 platform 至多 1 个 Variant（联合唯一）；Job 与 Variant 1:1 排期（改期=改时间不重建）。

## 4. 核心流程

**P1 发布链**：建 Post → 填/改 Variant → 账号页扫码登录（sidecar `/login` 返回二维码 PNG 给 UI，cookie 持久化到 `~/.publish-profiles/<平台>`）→ `plan` 预检（字数/媒体/步骤 dry-run）→ **人工点确认** → `publish` → **读回对账**（打开创作者中心作品列表，标题+时间窗对上才算 SUCCESS）→ PublishLog + 截图。

**排期**：worker 每分钟扫 due 的 Job，仅 `Variant=APPROVED` 的自动发（排期=已确认内容，AI 稿必须先批准）。

**抖音短信墙**：sidecar 事件上抛 → worker → Next API → UI 弹验证码输入框 → 回填续发。

**P2 创作**：主题(+素材图) → pi 会话：copywriting 出稿 → 按平台约束适配（字数/比例/标签，参考 Easel cross-platform-diff）→ formatCheck 校验 → 写 Variant(DRAFT) → UI diff 对比 + 可改 → 批准后走 P1 发布链。

**P3**：热点页实时拉 hotlist API（Easel `docs/../skills/shared/hotlist-apis.md`）→「从热点建内容」→ Post.fromHotlist；复盘：worker 每日 `collect` → PostMetric → pi 复盘 skill 出归因建议（存 Post 关联，不建新表）。

## 5. 风险与红线

1. 自动发布=平台风控风险（限流/封号）：**默认测试号**、单平台 ≤3 条/天、每次发布前确认（AI 稿 100% 需批准）——与 Easel 风险模型一致
2. IP：机房 IP 会被小红书拦登录；用家宽，或在干净网络登录后复制 `~/.publish-profiles/` 复用
3. 登录态目录在仓库外（`~/.publish-profiles/`），.gitignore 一切 profile/cookie/截图；密钥不进 commit
4. 不碰聊天室/公告/VIP 模块（09-30 既定）
5. 依赖新增：Playwright+chromium（sidecar 侧，Python）；pi SDK 为本机已装 npm 包
