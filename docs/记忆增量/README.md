# 记忆增量（机制细则）

- 每次「记忆:保存」把当天会话的**增量事实**追加到 `YYYY-MM-DD.md`（同一天追加同一文件）；只写新事实，不抄 AGENTS.md 与 `docs/项目记忆.md` 已有内容
- 四字段模板：

```markdown
# 记忆增量 YYYY-MM-DD

- 改动：<file>：<一句话>（原因/对应需求章节）
- 决策：<拍板内容及理由>
- 遗留：<TODO>
- 踩坑：<一句话>
```

- 单份 ≤50 行；超说明该「记忆:合并」进主快照（合并后删增量文件，git 历史即归档）
- 口令：`记忆:保存` / `记忆:合并` / `记忆:恢复`（默认增量，`全量` 按日期升序读全部）/ `提交推送` / `提交推送+记忆`
- 红线：记忆文件不进 CI/构建；不写密钥/环境变量值
- 自动恢复：会话开始或 `git pull` 后，读主快照 → 首读全量，之后只读晚于上次已恢复到的增量文件；主快照与增量矛盾时以增量为准
