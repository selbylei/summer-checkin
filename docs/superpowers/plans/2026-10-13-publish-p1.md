# 发布平台 P1 实现计划（发布核心：内容中枢 + 手动适配 + 扫码登录 + 自动发布 + 日志对账）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Web 端完成「建内容 → 各平台适配 → 扫码登录 → 预检 → 人工确认 → 自动发布 → 读回对账日志」全链路（小红书/抖音/公众号），排期任务自动执行已批准内容。

**Architecture:** 内嵌 pi 属 P2，P1 无 AI。进程拓扑按 YAGNI 简化：**不单独起 Python HTTP sidecar**（设计稿 §2 的 :3021 留到 P2/P3 有常驻需求再引），新增 Node worker（`server/publish-worker/`，:3022，tsx，沿用 ws:3001 模式）直接 `child_process` spawn vendor 的 Easel CLI 脚本；Next.js 新增 `src/app/publish` 路由组 + `api/publish/*` 代理（鉴权后 fetch worker）。新表 5 张（Post/PostVariant/PublishJob/PublishLog/AccountProfile；PostMetric 属 P3）。

**Tech Stack:** Next.js 16 App Router（写代码前先读 `node_modules/next/dist/docs/`）· Prisma 7（手工 SQL 迁移 + `prisma generate`）· vitest · tsx · Python 3（Playwright + chromium，仅发布时运行）

**Spec:** `doc/发布平台设计.md` v0.1（bf3fa1e）
