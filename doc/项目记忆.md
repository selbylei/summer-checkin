## 环境与红线

- 本机 Orca worktree：`~/orca/workspaces/summer-checkin/dev`（分支 selbylei/dev）；remote `github.com/selbylei/summer-checkin`
- 密钥只在 `.env`（DATABASE_URL / BETTER_AUTH_URL / CRON_SECRET 等），严禁进 commit 或记忆文件
- 聊天室 Origin 白名单 fail-closed：BETTER_AUTH_URL 配错会断整个聊天室，启动日志核对允许 Origins
- 写任何 Next.js 代码前先读 `node_modules/next/dist/docs/`（该版本有 breaking changes）
- 历史 schema 变更走手工 SQL 脚本（`prisma/*.sql`），Prisma 生成物固定放 `prisma/generated/`
